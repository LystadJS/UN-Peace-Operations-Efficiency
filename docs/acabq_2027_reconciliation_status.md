# 2027 ACABQ recommendations — source-access and numerical reconciliation status

**As of 8 October 2026 | Advisory reports, not adopted budget appropriations**

## Retrieval outcome

The official [ACABQ reports register](https://www.un.org/ga/acabq/en/reports) lists three relevant 2027 reports: **A/81/7** (first report, 6 October 2026), **A/81/7/Add.2** (SPM Cluster I, 25 August 2026) and **A/81/7/Add.3** (SPM Cluster II, 25 August 2026). The consulted register did not establish publication of **A/81/7/Add.4** for Cluster III.

**The complete report texts could not be read in the current environment**: public catalogues confirm bibliographic entries, but attempts to retrieve full text from the available UN document endpoints did not return readable report bodies. The user-provided PDF source package contains **A/81/6 (Sect.3)/Add.1–4**, the Secretary-General's proposals, **not** the ACABQ A/81/7 recommendation reports. This is an evidence-access blocker, **not an assumption that the ACABQ recommended no cuts**.
