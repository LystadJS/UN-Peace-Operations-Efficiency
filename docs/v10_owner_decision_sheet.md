## Decision requested

Decide whether an existing process has a specific source/version-control gap worth testing through **non-displacing shadow support**. Do not approve an office merger, new platform, changed mandate, reassigned clearance or budget reduction through this sheet.

| Question | Evidence the owners should provide | Current state |
|---|---|---|
| Where is the asserted gap? | One current source-to-output example and the control already used, including existing joint work. | Unreviewed. |
| Does equivalent functionality already exist? | Existing register/system or procedure; if equivalent, close the added proposal. | Unknown. |
| What exactly would be tested? | Component families, product IDs, language, eligible-claim rule, exclusions and input cutoffs. | Historical reference scope fixed; live scope pending. |
| What remains untouched? | Each owner's political/operational remit, clearance chain, required deadlines and normal-process fallback. | Required, not institutionally confirmed. |
| What burden is permitted? | Maximum additional person-minutes, setup allowance, deadline safety buffer and review window. | Unset; live start blocked. |
| Who can access which information? | Approved custodian, preparer/reviewer roles, storage, retention, incident route and staff notice. | Not assigned or approved. |
| How will comparison be credible? | Same sources/tasks/language/review requirements; prior exposure; all-enrolled failures; time-capture reconciliation. | Specified in protocol; not implemented live. |
| Who may stop/resume? | Both owner authorities and incident/remediation route, without changing their existing remits. | Not nominated. |

## Choose and document one disposition

**Retain existing process / close redundant proposal:** equivalent controls already exist or no additional gap is demonstrated.  
**Revise design:** identify the specific change and keep live gates closed.  
**Approve a bounded shadow only:** complete every activation item and sign the case-local receipt before any live collection.  
**Decline / defer:** record the reason without interpreting refusal as an unfavorable performance result.
